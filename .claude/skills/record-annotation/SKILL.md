# 기록 해설형 어노테이션 스킬

한강 강배 조사의 해설 카드 5점(NARA 영상 프레임 3 + 규장각 도판 2)에서 확정된 형식이다.

이 형식의 핵심은 디자인이 아니라 **한 문장의 약속**이다.

> **"화면에서 직접 읽히는 요소만 표시했습니다. 추정은 하지 않았습니다."**

이 문장을 카드 상단에 적는 순간, 범례의 모든 줄이 검증 대상이 된다.
그래서 이 스킬은 생성기보다 **검사기**가 더 중요하다.

---

## 1. 왜 판독과 추정을 분리하는가

법정 증언에 비유하면 이렇다. 목격자가 "키 180쯤 되는 남자가 뛰어갔습니다"라고 말하면
증언이지만, "범인이 도망쳤습니다"라고 말하면 그것은 판단이다. 둘을 섞으면 증언 전체의
신빙성이 떨어진다.

기록 해설도 같다. 실제 카드에서:

| 쓴 것 (판독) | 쓰지 않은 것 (추정) |
|---|---|
| 흰 상의·짧은 바지 차림의 인물 여럿 … **신원·소속은 기록에 없다** | "한국인 노무자들" |
| 상공의 회전익 항공기 한 대 — **기종은 판독 불가** | "H-5 헬리콥터" |
| 원형 개구부 — **용도는 화면만으로 판정 불가** | "환기구" |
| 칸마다 잔글씨가 적혀 있으나 **이 해상도에서는 판독되지 않는다** | (읽어낸 척) |

**"판독 불가"를 적는 것이 이 형식의 성취다.** 빈칸을 남기는 게 아니라,
빈칸이 어디인지를 명시하는 것이다. 그래야 다음 사람이 고해상 원본으로 그 지점만 다시 본다.

금지 어휘 목록과 대체 표현은 `references/reading_discipline.md` 참조.

## 2. 카드 구조 (5층)

```
① 제목        기록을 해설해 드립니다 ⑤ — 두 조운선의 차이
② 부제        이 컷을 왜 골랐는지 한 줄
③ 메타 표     6~7행. 앞 5행 고정 + 마지막 1~2행 가변
④ 스테이지    원본 이미지 + 점선 박스 + 번호 칩
⑤ 범례        번호별 관찰 + 근거 + 한계
⑥ 출처·고지   소장처 · 열람일 · 판독 한정 문구 · 권리 · 윤리
```

**메타 표 앞 5행은 고정**한다 — `제목 · 식별번호 · 생산 · 소재 · 시기`.
마지막 행만 카드 목적에 따라 갈아끼운다: `계보` / `판독 목적` / `판독 유의` / `형태` / `분류`.
그리고 **`권리` 행은 절대 빼지 않는다.**

## 3. 마커 배치 3원칙

1. **가리지 않는다** — 점선 영역 박스와 **외곽** 번호 칩만 쓴다.
   화살표·형광 하이라이트·반투명 오버레이 금지. 묵서와 선체를 덮으면 판독 근거가 사라진다.
2. **원본 화면비를 유지한다** — 잘라내거나 늘리지 않는다.
3. **좌표는 %로 쓴다** — 해상도가 달라져도 그대로 재사용된다.
   번호 칩은 박스 좌상단에서 대략 `left −4%, top −3%`. 왼쪽에 공간이 없으면 오른쪽으로 뺀다.

CSS 전문과 좌표 템플릿은 `references/card_spec.md`.

## 4. 실행

```bash
# 사양(JSON) → 단일 HTML (이미지 base64 임베드)
python scripts/build_annotation.py spec.json -o cards.html

# 검사 — 생성 전에 먼저 돌린다
python scripts/annotation_lint.py spec.json
```

검사기가 잡는 것:

| 검사 | 왜 |
|---|---|
| 추정 어휘 (`~로 보인다`, `~인 듯`, `아마`, `추정된다`) | 상단 약속과 모순 |
| 단정적 신원·소속 표현 | 기록에 없는 것을 적는 가장 흔한 사고 |
| 범례 번호 ↔ 박스 번호 불일치 | 마커만 있고 설명이 없는 상태 |
| 박스가 화면 밖으로 나감 | 좌표 오기 |
| `권리` 행 누락 / 등급 미표기 | 공개 전 관문 |
| 단위 환산 (척 → 미터) | 적용 척도 미확정이면 환산하지 않는다 |
| `판독 불가`류 표현이 **0건** | 모든 것이 읽혔다는 주장은 의심 대상 |

마지막 항목이 이 검사기의 성격을 보여준다. **"경고가 하나도 없는 것"이 오히려 경고다.**

## 5. 비교 판독 — 카드를 두 장으로 쪼갠다

같은 계열 자료 두 점을 **나란히 놓는 것 자체가 논증**이 된다.
실제 카드 ④⑤가 그렇게 만들어졌다.

```
④ 「漕船」    本板長 57척 : 中廣 13척
⑤ 「北漕船」  本板長 27.5척 : 中廣 17.5척
                    ↓
   두 비(比)가 서로 반대 방향  →  대소(大小) 차이가 아니라 선형(船型) 차이
```

한 장에 다 넣었으면 나오지 않았을 결론이다. 그리고 마지막에 반드시 붙인다 —
**"실물 대조로 검증할 것."** 도상에서 얻은 결론은 도상에서 끝나지 않는다.

## 6. 권리·윤리 고지

| 등급 | 표기 예 |
|---|---|
| B | `B · PD 추정 (17 U.S.C. §105) — 출판 전 인간 최종 확인 필요` |
| C | `C · 소장기관 허가 필요 — 본 건은 협조 취득 후 게재` |
| D | 게재 불가. 카드를 만들지 않는다 |

**윤리 고지는 별개다.** 피사체가 촬영을 거부할 수 없는 처지였다면 그것을 적는다.
실제 카드 ①의 마지막 문장이 그렇다 — 촬영을 거부할 수 없는 상황에서 기록된 노동임을 명시했다.
권리는 저작권자에 대한 예의고, 이 문장은 **피사체에 대한 예의**다.
