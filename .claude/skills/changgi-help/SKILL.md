# 창기창기 도와줘 — 사용 안내

이 스킬이 트리거되면 아래 내용을 **처음 사용자 눈높이의 친절한 안내**로 정리해 전달한다.
웹·모바일 사용자면 MCP `report_template(kind='help')` 응답과 동일 내용이다.
항상 시각 안내 페이지 링크를 함께 준다: **https://korea-archive-mcp.vercel.app/help.html**
(영어 사용자는 /help-en.html · 즉석 검색 데모 /ingitda.html · 실물 예제 /examples/hanriver.html·/examples/joseon-deck.html)

## 안내에 반드시 담을 것

1. **한 줄 소개** — 국내외 15개 아카이브에서 한국 관련 기록(1860~1960)을 발굴·검증하고
   전파물까지 만든다. 한국어 한 문장이면 충분(표기 변형·색인 언어 변환 자동).
2. **커넥터 연결 3단계** (웹·모바일) — 설정 → 커넥터 → 커스텀 커넥터 추가 →
   `https://korea-archive-mcp.vercel.app/api/mcp` — 로그인·키 불필요.
3. **매직 키워드 2개** —
   - "○○○ 풀패키지로 만들어줘": 조사→검증→매거진 보고서→카드뉴스→포스터→홍보·입문·
     메시지 카드→발표 PPTX→기록 해설→Canva→KARDA까지 전 산출물 자동
   - "창기창기 도와줘": 이 안내
4. **예시 문장** — 글로스터 연대(실전 1호)·장진호(실전 2호)·조선 한강 나루 행정(제도사)·
   병인양요 프랑스 기록·참조코드 인접 채굴·게재 권리 판정
5. **검증 4원칙** — 실물 기록만·원문 대조·출처 명시·정정 공개 → 통과본에만 검증 낙관
6. **FAQ** — 0건은 부재가 아니다(표기 변형·인접 채굴·관리 행정으로 전환) /
   ZIP은 로컬 전용(웹은 개별 아티팩트+manifest) / 이미지는 기관 공개 URL 참조 /
   조선 주제는 nedb_search 심층 판독 모드

## 톤

- 전문용어를 풀어 쓰고, 바로 복사해 쓸 수 있는 예시 문장을 강조한다.
- 마지막에 "지금 바로 한 문장 던져 보세요"류의 부담 없는 CTA로 닫는다.
- 웹·모바일에서 문구 인식이 안 될 때의 확실한 경로도 알려준다: 채팅창 + 메뉴 → 커넥터 프롬프트(changgi-help·full-package) 선택.
