# 한국사데이터베이스(db.history.go.kr) 참고문헌 작성 스킬

## 개요

이 스킬은 국사편찬위원회 한국사데이터베이스(이하 '한국사DB')에 수록된 자료를
학술 논문에 인용할 때의 **각주(footnote)** 및 **참고문헌(bibliography)** 형식을 자동으로 작성한다.

---

## 자료 유형 판별

사용자가 제공하는 정보(URL, 자료명, 날짜, 왕조/시대 등)로 아래 유형 중 하나로 분류한다.

| 유형 코드 | 자료 유형 | 대표 자료명 |
|-----------|-----------|------------|
| `A` | 조선시대 연대기 사료 | 조선왕조실록, 승정원일기, 일성록, 비변사등록, 각사등록 |
| `B` | 고려·전근대 사료 | 고려사, 고려사절요, 삼국사기, 삼국유사, 고려시대사료 |
| `C` | 법전·제도 자료 | 경국대전, 속대전, 대전회통, 증보문헌비고, 동국문헌비고 |
| `D` | 근현대 사료 (1876~1945) | 독립운동사료, 한국독립운동지혈사, 일제강점기 공문서, 신문·잡지 |
| `E` | 해방 이후 현대 자료 | 미군정기 문서, 정부 공문서, 국회 속기록 |
| `F` | 고문서·지방 자료 | 각종 고문서, 향토지, 읍지 |
| `G` | 한국사연대기·연구 자료 | 한국사연대기, 한국역대인물 종합정보시스템 |
| `H` | 해외 소재 자료 | 일본 외무성 문서, NARA 소장 한국 관련 문서 |

## 인용 형식 가이드

### 1. 국내 학술지 표준 형식 (국사편찬위원회·한국학중앙연구원 방식)

> **한국 역사학 논문의 기본 인용 형식**이며, 대부분의 국내 역사학 학술지가 이 방식을 준용한다.

#### 【유형 A·B·C】연대기·법전·전근대 사료

**각주 형식:**
```
『[자료명]』 [국왕 or 시대] [연도(간지)] [월] [일] ([간지 일자 or 기사 제목]).
```

**참고문헌 형식 (기사 ID 없을 때):**
```
『[자료명]』, 국사편찬위원회 한국사데이터베이스(http://db.history.go.kr), 검색일: YYYY.MM.DD.
```

**참고문헌 형식 (기사 ID 있을 때 — 직접 링크 포함):**
```
『[자료명]』 [왕명·연도·월일], 국사편찬위원회 한국사데이터베이스,
http://db.history.go.kr/id/[기사ID] (검색일: YYYY.MM.DD.)
```

**예시:**
- 각주: `『조선왕조실록』 세종 4년(1422) 3월 12일 (경술).`
- 각주(영문병기 시): `『朝鮮王朝實錄』(Joseon Wangjo Sillok), Sejong 4th year (1422), 3rd month, 12th day.`
- 참고문헌 (링크 없음): `『조선왕조실록』, 국사편찬위원회 한국사데이터베이스(http://sillok.history.go.kr), 검색일: 2026.03.13.`
- 참고문헌 (직접 링크): `『조선왕조실록』 세종 4년(1422) 3월 12일, 국사편찬위원회 한국사데이터베이스, http://sillok.history.go.kr/id/wda_10403012_005 (검색일: 2026.03.13.)`
- 참고문헌(법전): `『경국대전』, 국사편찬위원회 한국사데이터베이스(http://db.history.go.kr), 검색일: 2026.03.13.`

#### 【유형 D·E】근현대 사료

**각주 형식:**
```
[편찬/발행기관], 「[문서 또는 기사 제목]」, 『[총서·잡지·신문명]』 [권호] ([날짜]), [쪽수 or 면수].
```

**참고문헌 형식 (기사 ID 없을 때):**
```
[편찬기관]. 『[총서명]』. [권호정보]. 국사편찬위원회 한국사데이터베이스(http://db.history.go.kr), 검색일: YYYY.MM.DD.

http://db.history.go.kr/id/[기사ID] (accessed YYYY.M.D.)

**참고문헌 형식 (기사 ID 있을 때 — 2안):**
```
저자, 〈[문서 제목]〉 작성일.(편찬기관 편, 《[총서명 권호]》)
국사편찬위원회 한국사데이터베이스 http://db.history.go.kr, [기사ID], accessed YYYY.M.D.

**예시:**

- 참고문헌 (직접 링크 1안): `국사편찬위원회 편, 「3·1운동 관련 경성지방법원 판결문」(국사편찬위원회 편, 1990, 《한민족독립운동사자료집 제15권》) http://db.history.go.kr/id/hd_015r_0020_0140 (accessed 2026.3.13.)`

**각주 형식:**

### 2. 직접 링크(기사 ID URL) 생성 규칙 ★

> **국사편찬위원회 공식 권고**: 한국사데이터베이스의 모든 기사에는 고유한 **기사 ID**가 있으며,
> 이를 활용해 특정 자료로 바로 접근할 수 있는 **직접 링크**를 생성할 수 있다.

#### 직접 링크 URL 패턴
```
http://db.history.go.kr/id/[기사ID]
```

**예시:**
- 한용운 신문조서: `http://db.history.go.kr/id/hd_012r_0010_0310`
- 동아일보 1928.3.19 기사: `http://db.history.go.kr/id/np_da_1928_03_19_0030`
- 삼국사기: `http://db.history.go.kr/id/sg_004r_0040_0010`

> ⚠️ **조선왕조실록·승정원일기는 별도 사이트**에서 직접 링크 제공:
> - 조선왕조실록: `http://sillok.history.go.kr/id/[기사ID]`  
>   예: `http://sillok.history.go.kr/id/wnb_10102001_002`
> - 승정원일기: `https://sjw.history.go.kr` (날짜 검색으로 접근)

### 3. APA 스타일 (국제 학술지·영문 논문)

**원사료 (1차 사료) — 직접 링크 없을 때:**
```
[Title in Romanization] [[한글 제목]]. (n.d./[year of compilation]). 
Retrieved [Month Day, Year], from National Institute of Korean History Database: [사이트 URL]
```

**원사료 — 직접 링크 있을 때:**
```
[Title in Romanization] [[한글 제목]]. (n.d.). 
National Institute of Korean History. [직접 링크 URL]
```

**예시 (직접 링크 없음):**
```
Joseon Wangjo Sillok [조선왕조실록]. (n.d.). Retrieved March 13, 2026, from 
National Institute of Korean History Database: http://sillok.history.go.kr
```

**예시 (직접 링크 있음):**
```
Joseon Wangjo Sillok [조선왕조실록], Sejong 4.3.12. (n.d.). 
National Institute of Korean History. http://sillok.history.go.kr/id/wda_10403012_005
```

**근현대 편찬 자료 — 직접 링크 포함:**
```
[편찬기관 영문명]. ([Year]). [Title] [[한글 제목]] (Vol. [권호]). 
[Publisher]. http://db.history.go.kr/id/[기사ID]
```

## 주요 자료별 인용 패턴 레퍼런스

> 💡 **직접 링크 표기 원칙**
> - 기사 ID를 **알 때**: 직접 링크 URL `http://db.history.go.kr/id/[기사ID]` 를 참고문헌에 포함
> - 기사 ID를 **모를 때**: 사이트 홈 URL만 표기 후 `[기사ID 확인 필요]` 표시
> - 사용자가 URL을 제공하면 → ID를 자동 추출하여 직접 링크 생성

## Claude의 작동 지침

### Step 1: 자료 정보 수집
사용자가 다음 정보를 제공했는지 확인한다:
- **필수**: 자료명 (혹은 db.history.go.kr URL)
- **조선왕조실록/승정원일기 등**: 왕명, 재위연수 또는 서기연도, 월, 일, (간지)
- **근현대 자료**: 문서 제목, 발행기관, 날짜, 쪽수
- **신문**: 기사 제목, 신문명, 날짜, 면수
- **원하는 인용 형식**: 국내 표준 / APA / Chicago

### Step 2: 자료 유형 판별
위 유형 코드표(A~H)를 참조하여 자료를 분류한다.
URL이 제공된 경우 기사 ID 접두어로 자료를 자동 판별한다.

### Step 3: 직접 링크 처리 ★

| 사용자 제공 정보 | Claude 처리 방법 |
|--------------|--------------|
| `db.history.go.kr/id/[기사ID]` URL 제공 | ID 추출 → 직접 링크 포함 인용 생성 |
| `sillok.history.go.kr/id/[기사ID]` URL 제공 | 실록 직접 링크 포함 인용 생성 |
| URL 없이 자료명·날짜만 제공 | 사이트 홈 URL로 참고문헌 작성 + `[기사ID 확인 필요]` 안내 |
| 기사 ID만 제공 (URL 없음) | `http://db.history.go.kr/id/[기사ID]` 자동 조합 |

**직접 링크 포함 참고문헌은 국사편찬위원회 공식 권고 1안·2안 중 하나로 작성한다.**
(기본값: 1안 — 직접 링크 URL 방식)

### Step 4: 각주 + 참고문헌 동시 생성
사용자가 특정 형식을 지정하지 않으면 **국내 학술지 표준**으로 작성하되,
각주와 참고문헌 양식을 **모두** 제시한다.

### Step 5: 내용 요약 생성 ★

인용 형식 출력 **하단**에 해당 자료의 **내용 요약 3~4줄**을 항상 함께 제공한다.

**요약 작성 원칙:**
- 자료의 **사료적 성격·시대 배경·주요 내용**을 3~4줄로 압축
- 연대기 사료(실록·승정원일기 등): 해당 기사의 역사적 맥락과 기사 내용 설명
- 근현대 문서(판결문·신문조서 등): 문서 작성 배경, 피심문자·사건 개요
- 신문 기사: 기사 주제, 게재 시점의 사회적 맥락
- 법전·제도 자료: 해당 조문의 규정 내용과 시행 시기
- 사용자가 해당 자료의 내용을 제공한 경우 → 그 내용을 요약
- 사용자가 내용을 제공하지 않은 경우 → Claude의 사전 지식으로 자료 성격을 요약하되, 불확실한 내용은 `[원문 확인 필요]` 표시

**출력 형식:**
```
**각주 형식:**
[번호]. [각주 내용]

**참고문헌 형식:**
[참고문헌 항목]
🔗 직접 링크: http://db.history.go.kr/id/[기사ID]

📋 **내용 요약:**
[자료의 사료적 성격 또는 기사 배경 — 1줄]
[주요 내용 또는 사건 개요 — 1~2줄]
[역사적 의의 또는 연구 활용 가치 — 1줄]

> 💡 [형식 선택 이유 또는 주의 사항]
```

### Step 6: 부족한 정보가 있을 때
인용에 필요한 정보가 불완전한 경우, 작성 가능한 부분을 먼저 채우고
`[왕명]`, `[연도]`, `[기사ID]` 처럼 **꺾쇠 괄호**로 빈칸을 표시하여
사용자가 채울 수 있도록 안내한다.
기사 ID가 없으면 검색 방법을 함께 안내한다:
`http://db.history.go.kr` 검색 후 기사 상세 페이지 URL에서 `/id/` 이후 값이 기사 ID임을 설명.
