# 발굴조사 방법론 — 캐러셀의 재료를 캐는 법

콘텐츠형 캐러셀(역사·아카이브·기관·조사물)은 **조사의 깊이가 곧 콘텐츠의 차별성**이다.
남들이 아는 사실 나열이 아니라, 직접 발굴한 기록·디테일·반전이 카드가 된다.
이 문서는 조사 → 검증 → 카드 소재화의 전 과정이다.

## 1. 검색 전략: 넓게 → 좁게

- **1단계 재현율**: 일반 키워드로 전수 훑기 (컬렉션·시리즈 단위)
- **2단계 정밀도**: 식별번호 체계(RG·시리즈 코드)·연도·장소로 좁히기
- **3단계 정밀 타격**: 사건·인물·날짜 조합
- 쿼리가 길수록 0건이 잘 뜬다 — 0건이면 **단어를 빼면서** 재시도

### 표기 변형은 병렬 투입 (검색의 반은 표기다)
- **당대 표기가 열쇠**: 1945년 이전 한국 자료는 일본식 로마자로 색인돼 있다 —
  서울=Keijo, 인천=Jinsen, 부산=Fusan, 제주=Saishu(To), 한국=Chosen/Corea
- 인명 로마자 변형 전부: Lim/Im/Rim/Yim 같은 성씨 변형, 북한식 두음(임→림)
- 기관·주제도 옛 명칭·영문 명칭 병행 (사이트 title로 정식 명칭 확인)

### 교차검색
- 같은 대상을 **복수 아카이브에 동시에** 던진다 (해외: NARA·archive.org·TNA·위키미디어 /
  국내: 국사편찬위·국가기록원·국립중앙도서관·전문 아카이브)
- korea-archive MCP 도구가 연결돼 있으면 `cross_search`(연합검색)·`nara_search`·
  `koreanwar_item`(인접 채굴 내장) 등을 우선 사용. 없으면 각 기관 API·브라우저로
- 한 기관 API가 점검·오류면 그 사실을 기록하고 넘어간다 — "재조사 예정"도 카드 소재다

## 2. 인접 채굴 (Adjacent Mining) — 최고 수익률 기법

기록물 식별번호는 연속 생산된다. **하나를 찾으면 이웃 번호(±5~15)를 훑어라.**
- 예: 필름 111-ADC-5247을 찾았다면 5240~5260을 조회 — 같은 시기·같은 부대의
  미소개 기록이 줄줄이 나온다 (실전에서 이 방법으로 서울·제주 필름 6롤 + 공개된 개성 영상 발굴)
- archive.org는 `identifier:111-adc-52*` 와일드카드로 시리즈 전수 확인
- 같은 컬렉션의 "이웃은 공개됐는데 이것만 없다"는 발견 자체가 강력한 카드가 된다

## 3. 0건 ≠ 부재, 그리고 공개 상태 3단계

온라인 0건은 "없다"가 아니라 "전산화 전"일 가능성이 크다 (대형 아카이브의 카드 카탈로그
대부분이 미전산). 발굴 대상의 공개 상태를 **3단계로 판정**하라:

| 상태 | 판정 기준 | 카드 프레임 |
|---|---|---|
| 🟢 완전 공개 | 오픈 플랫폼(archive.org 등)에서 바로 열람 | 실물 프레임·스캔을 꺼내 보여준다 |
| 🟡 반쯤 공개 | 소장기관 카탈로그에는 디지털본 존재, 대중적으로 무명 | "있는데 아무도 안 봤다" — 카탈로그 실물 스크린샷 |
| 🔴 미공개 | 목록·촬영기록만 있고 본체는 수장고 | 번호·제목 목록 공개 + "깨우는 법" 안내 |

- 판정은 반드시 실검색으로: 카탈로그 페이지를 직접 열어(헤드리스 크롬 스크린샷)
  "1 Video"·"1 File(PDF만)" 같은 실태를 확인한다. 검색 결과 목록만 보고 단정하지 말 것
- 시점 의존 판정("미공개")은 조사 시점을 명시하고 게시 직전 재확인을 체크리스트에 넣는다

## 4. 메타데이터 검증 — 제목을 의심하라

- **제목 ≠ 내용**: 생산일자·원판번호·기술(記述)까지 읽는다.
  실례: '해방 기념식'이라는 제목의 영상이 생산일 확인 결과 1950년 수복 기념식이었다
- 검증에서 발견한 반전은 버리지 말 것 — **"제목만 믿으면 틀린다" 검증 노트 카드**는
  콘텐츠의 백미이자 계정 신뢰 장치다
- 원문 판독 디테일(현수막의 연호, 사진 뒷면 메모, 발행일란 표기)이 최고의 2번 카드 소재다

## 5. 조사 결과 → 카드 소재 변환표

| 조사 산출물 | 카드 유형 (layouts.md) |
|---|---|
| 실물 이미지·프레임 | 커버·폴라로이드·파노라마 |
| 판독 디테일 (손글씨·연호·번호) | 디테일 후킹·인용 박스 |
| 검증 반전 (오표기·재판정) | 검증 노트 (반전 박스) |
| 미공개 목록 (번호+제목) | 필름캔 목록·부채꼴 스택 |
| 기관별 검색 결과 (건수·0건 포함) | 기관 정리(.org) — 0건도 정직하게 표기 |
| 촬영지·소장지 분포 | 지도 여정 |
| 공개 상태 판정 | 3단계 tier + 상태 배지 |
| 재현용 검색 쿼리 | 따라하기 카드 — 재현성이 신뢰다 |

## 6. 조사 기록 원칙

- 실행한 쿼리와 결과 건수를 기록해 둔다 — "따라하기" 카드와 캡션의 재현 검색이 된다
- 확인일을 남긴다 ("2026. 8 실검색 기준")
- 실패한 검색(0건·API 오류)도 기록 — 정직한 한계 표기가 신뢰를 만들고, 후속 콘텐츠가 된다
- 권리 판정은 조사 단계에서 함께 (image-sourcing.md의 판정표) — 카드 만들고 나서
  못 쓰는 이미지로 판명되면 재작업이다
