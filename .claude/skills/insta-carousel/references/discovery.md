# 발굴조사 방법론 — 캐러셀의 재료를 캐는 법

콘텐츠형 캐러셀(역사·아카이브·기관·조사물)은 **조사의 깊이가 곧 콘텐츠의 차별성**이다.
남들이 아는 사실 나열이 아니라, 직접 발굴한 기록·디테일·반전이 카드가 된다.
이 문서는 조사 → 검증 → 카드 소재화의 전 과정이다.

## 1. 검색 전략: 넓게 → 좁게

- **1단계 재현율**: 일반 키워드로 전수 훑기 (컬렉션·시리즈 단위)
- **2단계 정밀도**: 식별번호 체계(RG·시리즈 코드)·연도·장소로 좁히기
- **3단계 정밀 타격**: 사건·인물·날짜 조합
- 쿼리가 길수록 0건이 잘 뜬다 — 0건이면 **단어를 빼면서** 재시도

### 표기 변형은 병렬 투입 (검색의 반은 표기다)
- **당대 표기가 열쇠**: 1945년 이전 한국 자료는 일본식 로마자로 색인돼 있다 —
  서울=Keijo, 인천=Jinsen, 부산=Fusan, 제주=Saishu(To), 한국=Chosen/Corea
- 인명 로마자 변형 전부: Lim/Im/Rim/Yim 같은 성씨 변형, 북한식 두음(임→림)
- 기관·주제도 옛 명칭·영문 명칭 병행 (사이트 title로 정식 명칭 확인)

### 교차검색
- 같은 대상을 **복수 아카이브에 동시에** 던진다 (해외: NARA·archive.org·TNA·위키미디어 /
  국내: 국사편찬위·국가기록원·국립중앙도서관·전문 아카이브)
- korea-archive MCP 도구가 연결돼 있으면 `cross_search`(연합검색)·`nara_search`·
  `koreanwar_item`(인접 채굴 내장) 등을 우선 사용. 없으면 각 기관 API·브라우저로
- 한 기관 API가 점검·오류면 그 사실을 기록하고 넘어간다 — "재조사 예정"도 카드 소재다

### 아카이브별 실전 수칙 (요점만 — 기관 구조 전체는 MCP `source_profile` 참조)

| 아카이브 | 입구 | 실전 수칙 |
|---|---|---|
| NARA (catalog.archives.gov) | RG(레코드 그룹) | RG 111 통신대 영상·RG 242 노획문서·RG 80/127 해군·해병 사진이 한국 밀집 구간. 카탈로그 단위는 NAID, 필름은 로컬넘버(예: 111-ADC-####) — 둘 다 기록. 상세 페이지의 "1 Video"/"N Images" 표기가 디지털 사본 존재 증거다 |
| TNA Discovery | 참조코드 (WO/FO/CO/ADM+시리즈/피스) | 시리즈를 특정하면 피스 번호 인접 훑기. Discovery는 영국 전역 2,500개 기관 연합목록 — `heldBy`(소장처)를 꼭 확인, TNA 소장이 아닐 수 있다 |
| archive.org | identifier·collection | `identifier:111-adc-52*` 와일드카드로 시리즈 전수. **업로더 ≠ 권리자** — 원판 소장기관을 별도 확인해 출처 대장에 쓴다 |
| Wikimedia Commons | 카테고리 트리 | 검색보다 카테고리 횡단(Category:1945 in Korea류)이 수율이 높다. 파일 페이지의 Source/Author/License 필드가 출처 대장의 1차 재료 |
| 국내 (한국사DB·국가기록원· KOREAN WAR ARCHIVES 등) | 한글 재기술 | KOREAN WAR ARCHIVES는 NARA 시청각 기록의 한국어 재기술본 — **한글로 검색해 NAID로 원본에 직결**하는 우회로다. 협약기관 기록은 출처 표기 필수 |

## 2. 인접 채굴 (Adjacent Mining) — 최고 수익률 기법

기록물 식별번호는 연속 생산된다. **하나를 찾으면 이웃 번호(±5~15)를 훑어라.**
- 예: 필름 111-ADC-5247을 찾았다면 5240~5260을 조회 — 같은 시기·같은 부대의
  미소개 기록이 줄줄이 나온다 (실전에서 이 방법으로 서울·제주 필름 6롤 + 공개된 개성 영상 발굴)
- archive.org는 `identifier:111-adc-52*` 와일드카드로 시리즈 전수 확인
- 같은 컬렉션의 "이웃은 공개됐는데 이것만 없다"는 발견 자체가 강력한 카드가 된다

## 3. 0건 ≠ 부재, 그리고 공개 상태 3단계

온라인 0건은 "없다"가 아니라 "전산화 전"일 가능성이 크다 (대형 아카이브의 카드 카탈로그
대부분이 미전산). 발굴 대상의 공개 상태를 **3단계로 판정**하라:

| 상태 | 판정 기준 | 카드 프레임 |
|---|---|---|
| 🟢 완전 공개 | 오픈 플랫폼(archive.org 등)에서 바로 열람 | 실물 프레임·스캔을 꺼내 보여준다 |
| 🟡 반쯤 공개 | 소장기관 카탈로그에는 디지털본 존재, 대중적으로 무명 | "있는데 아무도 안 봤다" — 카탈로그 실물 스크린샷 |
| 🔴 미공개 | 목록·촬영기록만 있고 본체는 수장고 | 번호·제목 목록 공개 + "깨우는 법" 안내 |

- 판정은 반드시 실검색으로: 카탈로그 페이지를 직접 열어(헤드리스 크롬 스크린샷)
  "1 Video"·"1 File(PDF만)" 같은 실태를 확인한다. 검색 결과 목록만 보고 단정하지 말 것
- 시점 의존 판정("미공개")은 조사 시점을 명시하고 게시 직전 재확인을 체크리스트에 넣는다

## 4. 사실검증 워크플로우 — 제목을 의심하라

카드에 넣을 모든 사실은 아래 5단계를 거친다. 순서대로, 생략 없이:

1. **제목 ↔ 생산일자·기술(記述) 대조** — 카탈로그 상세·API 원문을 연다. 제목은 후대에
   붙은 요약일 뿐이다. 실례: '해방 기념식'이라는 제목의 영상이 생산일 확인 결과
   1950년 수복 기념식이었다
2. **식별번호 역추적** — 원판번호·NAID·참조코드로 원 소장기관 카탈로그에 직결해
   같은 기록인지 확인한다. 재업로드본·재기술본은 식별번호가 유일한 연결고리다
3. **복수 기관 교차 대조** — 같은 기록의 한·영 재기술본을 맞춰 본다. 기술 불일치
   (날짜가 다르다, 장소가 다르다)는 오류 신호이자 **최고의 카드 소재**다
4. **어록·수치는 1차 출처만** — 실증 안 된 어록 금지(전승은 "전해지는 말" 표기).
   검증 불가한 비교("○○시보다 많다") 대신 산술로 환원("매일 100가구꼴")
5. **정정 이력 기록** — 처음 판단 → 정정 근거 → 확인일을 남긴다. 정정 과정 자체가
   "제목만 믿으면 틀린다" 검증 노트 카드가 된다

- 원문 판독 디테일(현수막의 연호, 사진 뒷면 메모, 발행일란 표기)이 최고의 2번 카드 소재다

## 5. 필드 조사 — 디지털 밖의 기록 (다락방·인터뷰)

온라인 아카이브는 발굴의 반쪽이다. 사진첩·유품·편지는 다락방과 기억 속에 있고,
**캐러셀의 CTA 자체가 제보 채널**이 된다("집에 이런 사진 있으면 DM 주세요").

1. **제보·단서 수집** — 댓글·DM·유족회·지역 향토사학회·참전용사 모임. 제보가 오면
   "무엇을, 누가, 언제부터 갖고 있었나"(전래 경위)를 먼저 묻는다 — 전래 경위가 진위의 반이다
2. **사전 조사** — 인터뷰 전에 소장자·대상 인물의 공개 기록(병적·훈격·신문 DB)을 먼저 찾는다.
   인터뷰는 백지에서 시작하는 수집이 아니라 **확인**이다
3. **인터뷰 수칙** — 녹취·촬영 동의를 먼저 받는다(기록으로 남김). 열린 질문("그날 어땠나요")
   → 구체 확인("이 사진 속 장소가 어디인가요") 순서. 기억은 사료가 아니라 단서다 —
   날짜는 사건 기준으로 캘리브레이션("전쟁 나던 해 가을"→1950년 가을), 실물·문서로 역추적한다
4. **실물 촬영·디지털화** — 원본 훼손 금지(스캔 압착보다 자연광 정면 촬영 우선).
   **앞뒷면 모두** 촬영 — 뒷면 메모·도장·인화소 마크가 최고의 소재다. 크기 기준물(자·동전)과
   함께 한 컷, 보관 상태(앨범째·봉투째)도 한 컷
5. **권리·존엄** — 게재 동의는 서면·메시지 기록으로 받는다. 생존 인물이 식별되면 본인(또는
   유족) 동의 필수. 포로·사망자·학살 피해자는 게재윤리(존엄) 기준을 아카이브 기록과 동일 적용
6. **교차검증으로 환류** — 구술에서 나온 부대명·날짜·지명을 **새 검색어로 변환**해 §1~2로
   돌아간다. 다락방에서 나온 사진 한 장이 인접 채굴의 시드가 된다

## 6. 조사 결과 → 카드 소재 변환표

| 조사 산출물 | 카드 유형 (layouts.md) |
|---|---|
| 실물 이미지·프레임 | 커버·폴라로이드·파노라마 |
| 판독 디테일 (손글씨·연호·번호) | 디테일 후킹·인용 박스 |
| 검증 반전 (오표기·재판정) | 검증 노트 (반전 박스) |
| 미공개 목록 (번호+제목) | 필름캔 목록·부채꼴 스택 |
| 기관별 검색 결과 (건수·0건 포함) | 기관 정리(.org) — 0건도 정직하게 표기 |
| 촬영지·소장지 분포 | 지도 여정 |
| 공개 상태 판정 | 3단계 tier + 상태 배지 |
| 필드 조사 실물 (앞뒷면·전래 경위) | 폴라로이드·디테일 후킹 + "제보로 찾았다" 서사 |
| 재현용 검색 쿼리 | 따라하기 카드 — 재현성이 신뢰다 |

## 7. 조사 기록 원칙

- 실행한 쿼리와 결과 건수를 기록해 둔다 — "따라하기" 카드와 캡션의 재현 검색이 된다
- 확인일을 남긴다 ("2026. 8 실검색 기준")
- 실패한 검색(0건·API 오류)도 기록 — 정직한 한계 표기가 신뢰를 만들고, 후속 콘텐츠가 된다
- 권리 판정은 조사 단계에서 함께 (image-sourcing.md의 판정표) — 카드 만들고 나서
  못 쓰는 이미지로 판명되면 재작업이다
