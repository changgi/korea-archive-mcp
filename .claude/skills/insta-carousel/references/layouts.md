# 레이아웃 아키타입 카탈로그

`assets/card_styles.html`의 컴포넌트로 조립하는 검증된 카드 유형들.
**한 캐러셀에 서로 다른 아키타입을 3개 이상 섞어라** — 같은 틀 반복은 스와이프를 죽인다.

## 커버 계열
- **풀블리드 커버**: 실물 이미지 전면 + 하단 그라디언트 + h1 훅 2줄 + 도장(.stamp).
  이미지의 얼굴/피사체가 텍스트에 가리지 않게 object-position 조정
- **필름스트립 커버**: 타이포 중심 + 하단에 시리즈 대표 이미지 6~7컷 스트립(.strip)

## 증거(이미지) 계열
- **폴라로이드 단독**: .polaroid + .tape — 이미지 1장 + 캡션 + 리드. 기본형
- **폴라로이드 듀오/그리드**: 2컷 나란히(살짝 어긋난 margin-top), 4컷 2×2, 6컷 3×2.
  듀오는 각 컷 height 400~430, 6컷은 215 안팎으로
- **파노라마 필름스트립**(.pano): 스프로킷 테두리 안에 3컷 가로 배열 — 영상 프레임·연속
  장면에 최적. height 300
- **인물 카드**: 좌측 세로 폴라로이드(flex 0 0 330~400px, height 430~560) + 우측
  이름(h2)·생몰(.years)·업적 리드·어록(.quote). 인물 시리즈의 기본형
- **대형 확대 컷**(.shot): "그중 한 컷을 확대하면" — 디테일 후킹 카드. height 400~470

## 구조화(정보) 계열
- **빅넘버**: 190px 숫자 하나가 카드의 주인공. 리드는 산술 근거
- **타임라인**(.tl): 세로 점선 + 연도 마커 4~6개. 정리 카드의 기본
- **기관/결과 목록**(.org): 좌 골드 보더 행 4~5개 + 건수 배지(✓·0건·△)
- **필름캔/기록 목록**(.reel): 식별번호(모노스페이스) + 제목 + 상태 배지(.b-open/.b-half/.b-lock)
- **3단계 분류**(.tier): 🟢🟡🔴 신호등 3열 — 상태·등급 개념 설명에
- **지도 여정**: 인라인 SVG 지도(약식 실루엣) + 지점 마커(circle+ring) + 점선 경로 +
  38선 같은 상징선. 라벨은 마커와 겹치지 않게 좌표를 렌더 후 확인. 우측에 .reel 목록 병치
- **인용/조문 박스**(.docquote/.quote): 원문(한자·영문) + small 현대어 병기

## 겹침(레이어) 계열 — 규칙 엄수
- **부채꼴 스택**(.fanwrap+.fcard): 종이 카드 3~4장을 회전(±3~6deg)·계단 배치.
  잠긴 기록·문서 뭉치 표현에 최적. **제목(h2) 영역을 절대 침범하지 않게** fanwrap을
  제목 아래에 두고 top 좌표를 계단식으로. 맨 위 카드의 정보가 완전히 보이게, 아래 카드는
  번호·제목 일부만 보여도 미학적으로 OK
- **카탈로그 스크린샷 겹침**: 실물 스크린샷을 .fcard 안에 넣어 2장 겹침 — "기록이 실존한다" 증거

## 검증 노트 계열
- **반전 박스**: 좌 크림슨 보더 박스에 반전 사실("생산일: 1950. 9. 29") + 아래 교훈 리드
- **디테일 판독**: 원문 인용 박스 + "확대하면 ○○이 보인다" 리드 (연호·손글씨·번호)

## CTA 계열
- 풀블리드(어둡게 brightness .45~.55) + h1 선언문 + 행동 1개 + credit 고지.
  이미지는 본편에서 가장 감정적인 컷 재사용

## 공통 안전 규칙
- 모든 카드 콘텐츠는 `.col`(하단 안전영역 150px) 안에. credit은 고정 마진(auto 금지)
- 이미지 전부 고정 height + object-fit:cover (문서 스캔·연속컷 비교는 contain + 어두운 배경)
- 제목 줄바꿈은 의미 단위 <br>, keep-all 유지 — 렌더 후 고아 단어 확인
