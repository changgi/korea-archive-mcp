# 카드뉴스 카피라이팅 · 캡션 · 해시태그

## 1. 후킹 카피 공식 (커버)

커버의 목표는 "8초 안에 스와이프 결정". 설명하지 말고 긴장을 만든다.

- **공식 A — 행동→뜻밖의 결과**: [작은 행동] + [규모가 다른 결과].
  "검색창에 이름 석 자 넣었더니, 73년 전 앨범 42컷이 쏟아졌다"
- **공식 B — 통념 뒤집기**: "8월 15일 정오, 거리는 조용했다" / "'0건'이 나와도 기록은 있다" /
  "광복절의 8월 15일은 사실 두 번이다"
- **공식 C — 부재의 폭로**: "이 필름을 본 한국인은 거의 없다" / "80년째 상영되지 않은 필름들이 있다"
- **공식 D — 메이커 서사** (도구·제품): 문제 → "그래서 우리가 직접 만들었다" → 검증된 숫자
- 숫자는 구체적으로(42컷, 30분), 시간은 대비되게(석 자↔73년)

**디테일 후킹(2번 카드)**: 가장 작고 구체적인 디테일 하나를 확대 — 손글씨, 연호, 원판번호,
데이터 이상치. "확대해 보면 —" 같은 진행형 문장이 잘 붙는다.

## 2. 카드별 카피 규칙

- 제목 2줄 이내, 줄바꿈은 의미 단위로. 렌더 후 고아 단어(한 단어 줄) 확인
- 강조(골드)는 카드당 1~2곳. 리스트는 3~4항목이 한계
- 이미지 캡션은 감상이 아니라 정보 — "무엇을 보고 있는지"
- CTA는 행동 1개만
- 어록·인용은 실증된 것만. 전승 어록은 "— 전해지는 말" 표기 + 고지 한 줄

## 3. 게시 캡션 — 한 줄 한 호흡 (후킹형)

**긴 문단은 인스타에서 죽는다.** 스크롤 중 멈춰 읽게 만드는 시각적 리듬이 목적:
- 오프닝은 질문 또는 단문 선언 1줄, 바로 빈 줄
- 한두 문장마다 빈 줄 — 문단이 아니라 호흡 단위로 끊는다
- 짧은 문장. 접속사보다 줄바꿈. 반전은 "그리고 —" 뒤에 빈 줄

**예시 (이 리듬을 따를 것):**
```
이 필름, 본 적 있으세요?

없을 겁니다.
한국에 소개된 적이 거의 없으니까요.

1945년 개성.
시민들이 손수 쓴 영어 현수막.

그리고 —
이런 캔이 여섯 개 더 있습니다.
```
- 나열부는 이모지 불릿(🟢🟡🔴, 📷, 🎞)으로 구조화
- 마무리: CTA(댓글 유도) → 구분선(―――) → 출처·권리 고지 → 해시태그

`caption.txt` 구성: ①본문 캡션 ②릴스/스토리용 짧은 버전(3~4줄)
③해시태그 ④게시 전 체크리스트(권리 확인·카드 순서·재확인 사항)

## 4. 해시태그 전략

- 본문 ~20개: 대형(도달) 1/3 + 주제 1/3 + 니치·고유 1/3. 첫 댓글에 확장 세트 10~15개
- 시의성 태그 제안 (기념일·시즌 — 예: 8월 #광복절, 6월 #호국보훈)
- 고유명 태그는 도달이 없어도 아카이빙용으로 1~2개 유지

## 5. 출처·권리 문구 (이미지 카드 필수)

**표준 형식** — 카드 캡션: `출처: [기관 정식 명칭], [식별번호] ([라이선스])`
캡션(게시글) 출처 절: 기관·컬렉션·식별번호에 **확인일과 열람 URL**까지.
모든 출처 문구는 소싱 때 작성한 `sources.txt` 대장에서 가져온다(image-sourcing.md §4).

예시:
- 카드: `출처: 미국 NARA RG 111, 111-ADC-5280 (퍼블릭 도메인)`
- 카드: `출처: KOREAN WAR ARCHIVES(전쟁기념관), 2022-US-02-AV-D-00197`
- 캡션: `사진: 미국 국립문서기록관리청(NARA) RG 111, 원판 111-ADC-5280 —
  archive.org/details/111-adc-5280 (퍼블릭 도메인, 2026. 8 확인)`

원칙:
- **원 소장처+식별번호가 본 출처**, 내려받은 사본처(위키미디어 등)는 부기.
  식별번호를 아는데 생략하면 부정확한 출처다
- 정식 명칭은 사이트 title로 확인 (통칭을 쓰면 정정 요청이 온다)
- CC 계열은 저작자명 포함, "크레딧 삭제 금지"를 체크리스트에 명시
- 라이선스 미확정: 카드에 출처를 넣되 납품 시 "게시 전 [기관] 확인" 안내 필수
- 인물(고인·피해자·군인) 식별 사진: 존엄 존중 문구를 캡션 또는 마지막 카드에
- 시점 의존 주장("미공개" 등)은 "○○년 ○월 조사 시점 기준" 명시 + 게시 직전 재확인 권고
