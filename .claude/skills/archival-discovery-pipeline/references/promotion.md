# 전파 기획과 홍보글 작성

발굴 결과를 대중에게 알리는 방법.

## 기본 자세

**발굴은 자랑이 아니라 전달이다.**

57건을 찾은 것보다 **찾는 방법을 넘기는 것**이 중요하다.
「0건 vs 14건」을 본 사람이 자기 주제로 같은 시도를 한다면 그것으로 성공이다.

---

## 하나의 질문으로 묶는다

발굴 성과를 나열하면 아무도 보지 않는다. **전체를 관통하는 질문 하나**를 세운다.

> ### 「해방기 영상은 왜 유튜브에 없을까?」
> 없어서가 아니다. **「제주」로는 0건, 「SAISHU」로는 나온다.**

이 한 문장이 시리즈 전체를 지탱한다. 개별 발굴은 이 명제의 증거로 배치된다.

## 세 층위

| 층위 | 메시지 | 대상 |
|---|---|---|
| 표층 | 「1947년 서울이 컬러로」 | 일반 — 놀라움 |
| 중층 | 「원 기술 한 줄이 11분을 가린다」 | 관심층 |
| **심층** | **「검색어를 바꾸면 찾을 수 있다」** | **연구자 — 방법 전수** |

**심층이 목적이다.** 표층은 사람을 데려오는 수단일 뿐이다.

---

## 캡션 필수 4요소

```
1. 후킹 문장   (첫 줄 — 피드에서 잘리기 전)
2. 발견 요약   (2~3문장)
3. ⚠️ 확인하지 못한 것  ★ 예외 없이
4. 출처 링크
```

### 예시

> **「제주」라는 단어가 이 필름 기술에 한 글자도 없습니다.**
>
> 1945년 10월, 제주에서 일본군 장비가 처리되는 장면입니다.
> 원래 기술은 `DESTRUCTION OF JAPANESE EQUIPMENT, ISLAND OF SAISHU, KOREA`.
> 사이슈는 제주의 일본식 독음입니다.
>
> 「파괴」는 두 가지였습니다. 바다에 버리고, 육지에서 태우고.
>
> ⚠️ 정확한 촬영 항구는 확정하지 못했습니다. 부대 식별과 인물 비정도 하지 않았습니다.
>
> 🔗 archive.org/details/111-adc-5395

### 「⚠️ 확인하지 못한 것」은 예외가 없다

오프닝과 마무리 회차에도 넣는다. 쓸 것이 없어 보여도 찾아 적는다.

- 오프닝 → 「미공개로 남은 것이 훨씬 많습니다」
- 방법 편 → 「이 여섯 가지가 완결된 방법론은 아닙니다」
- 게재 원칙 편 → 「이 판정이 옳다고 주장하지 않습니다」

## 절대 쓰지 않을 표현

| 표현 | 이유 |
|---|---|
| 「최초 공개」 「단독 발굴」 | 재공개된 자료이며 누구나 볼 수 있다 |
| 「충격」 「경악」 「소름」 | 포로·사망자·아동 관련 자료다 |
| 민감 사건 단정 | 시기가 겹칠 뿐 판별할 수 없다 |
| 인물 실명 비정 | 슬레이트 표기 외에는 하지 않는다 |

## 플랫폼별 전략

| 플랫폼 | 방식 |
|---|---|
| **인스타그램** | 캐러셀 10장 전부. 이탈률이 높아도 **끝까지 보는 사람이 목표 독자** |
| **스레드·X** | 1~3장만 + 링크 유도. **수치 대비**가 잘 퍼진다 |
| **링크드인·블로그** | 보고서 전문. 실무자 대상 — 방법론을 전면에 |
| **유튜브** | 영상 자체 편집(게재 제한 대상 제외). 자막이 곧 재기술의 배포 |

### 단문 예시 (확산용)

```
Busan → 0건
Pusan → 14건

Gaeseong → 0건
Kaesong → 6건

0건은 부재가 아니라 표기의 불일치일 수 있습니다.
```

## 릴스·숏폼 (30초)

| 항목 | 규칙 |
|---|---|
| 첫 3초 | **수치나 질문**으로 시작. 설명 금지 |
| 자막 | 무성 시청 전제 — 화면에 크게 |
| 음악 | 잔잔한 것. **비장한 곡 금지**(자극 유발) |
| 화면 | 게재 제한 대상은 릴스에도 쓰지 않음 |
| 마무리 | 캐러셀·보고서로 유도 |

### 대본 예시

| 초 | 자막 |
|---|---|
| 0~3 | **"제주"로 검색하면** |
| 3~5 | **0건** |
| 8~11 | **"SAISHU"로 검색하면 나옵니다** |
| 26~30 | **자료가 없는 게 아니라 도달되지 않은 것입니다** |

## 성과 측정

조회수가 목표가 아니다.

| 지표 | 의미 |
|---|---|
| 마지막 장 도달률 | 심층 메시지에 닿은 비율 |
| 저장·공유 | 실무자 반응 |
| 보고서 링크 클릭 | 방법을 배우려는 사람 |
| 원문 아카이브 유입 | **실제 열람으로 이어졌는가** |
| **「나도 찾아봤다」 언급** | **최종 목표 — 방법의 전파** |

마지막 지표가 성공 여부를 가른다.

## 게시 전 최종 점검

- [ ] 캡션에 **⚠️ 확인하지 못한 것**이 있는가

- [ ] 게재 제한 대상이 섞이지 않았는가

- [ ] 민감 사건 단정이 없는가
- [ ] 인물 실명 비정이 없는가
