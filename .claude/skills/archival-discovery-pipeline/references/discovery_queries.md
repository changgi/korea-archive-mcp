# 판독 중 재검색

> ⚠ **처음 자료를 찾는 전략은 여기 없다.**
> `korea-archive-discovery` 플러그인의 `references/query_cheatsheet.md`가 정본이다.
> 이 문서는 **판독 중 새 단서가 나와 다시 찾을 때** 쓴다.

## 판독에서 나오는 재검색 단서

| 판독한 것 | 다시 찾을 것 | 도구 |
|---|---|---|
| ROLL 3 | ROLL 1·2 | `nara_search` |
| 과제번호 (FEC 67 등) | 같은 과제의 다른 릴 | `nara_search` |
| 촬영자명 | 같은 촬영자의 다른 자료 | `nara_search` |
| 지명 당대 표기 | 그 표기로 확장 검색 | `nara_search` · `ia_search` |
| 부대명 | 같은 부대의 다른 기록 | `nara_search` |
| 참조코드 | 인접 ±8 순회 | `tna_adjacent_mine` |

**이 왕복이 계열 복원의 핵심이다.** 한 번 검색하고 끝내면 자매편을 놓친다.

**볼드가 당대 표기다.** 1945년 이전 자료는 이쪽으로 검색해야 나온다.

### 매체·기법

컬러 자료를 찾을 때는 **필름 상표명**이 가장 정확하다.

```
kodachrome    ← 컬러 홈무비 특정에 가장 효과적
"home movie"  ← 개인 촬영분
8mm · 16mm
```

`color` 단독 검색은 효과가 낮다. 흑백 자료의 기술에도 등장하기 때문이다.

> **매체의 이름을 알아야 그 매체로 찍힌 것을 찾을 수 있다.**

## 검색 전략 넷

### ① 표기 변형 병렬 투입

한 번에 한 표기만 넣지 말고, 변형을 모두 시도한다.
같은 자료가 다른 표기로 두 번 나오면 자매편일 수도, 중복일 수도 있다.

### ② 기록군 교차 검색

같은 사건이 여러 기록군에 흩어져 있다.
한 기록군에서 찾았다고 멈추지 않는다.

**부처를 달리하면 같은 문서가 다른 참조코드로 나온다.**
실제 사례: 1889년 영사 보고서가 외무성·군부·개인 문서 **네 곳**에 중복 소장.

### ③ 연도별 전수 스캔

`Korea 1945` `Korea 1946` … 연도를 바꿔 가며 훑는다.
연도에 따라 자료량이 수십 배 차이 난다.

### ④ 인접 확장

찾은 자료의 참조코드 **±15** 범위를 순회한다.
연속 촬영분이 인접 번호에 배치되는 경우가 많다.

**성과가 없어도 시도를 기록한다.** 다음 사람의 중복 조사를 막는다.

---

## 재공개 여부 확인

카탈로그에 있다고 볼 수 있는 것이 아니다.

```
identifier:<접두어>*        → 해당 계열의 재공개분 전수
identifier:<접두어>* AND korea   → 그중 한국 관련
```

**같은 자료가 다른 식별자 형식으로 올라와 있을 수 있다.**
접두어를 달리해 재검사한다. 한 형식으로만 조회하면 놓친다.

---

## 0건이 나왔을 때

종료하지 말고 순서대로 시도한다.

1. **표기 변형** 전부 투입
2. **연도·기록군** 바꿔 재조회
3. **인접 참조코드** 순회
4. **다른 아카이브**로 이동
5. **국내 소장 현황** 확인 ← 이것을 먼저 했어야 할 수도 있다

### 국내 확인을 먼저 하라

해외 아카이브를 뒤지기 전에 국내에 무엇이 있는지 본다.
**중복을 피하려는 것이 아니라, 자기 작업이 무엇의 옆에 놓이는지 알기 위해서다.**

실제로 국내 기관이 이미 수집해 한국어 제목까지 부여한 자료가 상당수 있을 수 있다.
다만 **시기별로 고르지 않다** — 특정 시기는 통째로 비어 있기도 하다.

---

## 미전산화 자료

온라인 0건이 최종 답이 아니다.

대형 아카이브의 카드 카탈로그 상당수가 **미전산화 상태**다.
온라인 검색은 빙산의 일각일 수 있으며, 현지 열람이나 복제 신청이 필요하다.

**보고서에 반드시 명시한다:**

```
⚠ 0건 ≠ 부재
현행 표기로는 0건이나 당대 표기로는 N건이 반환된다.
또한 카드 카탈로그 대부분이 미전산화 상태이므로,
온라인 0건에서 조사를 종료해서는 안 된다.
```

## 재현 쿼리 기록법

산출물에 **실제 실행해 결과를 얻은 쿼리만** 적는다.

```markdown
| 목적 | 쿼리 | 결과 |
|---|---|---|
| 제주(일본식 독음) | `SAISHU` | 1건 |
| 부산(구 로마자) | `PUSAN` | 14건 — 현행 Busan은 0건 |
| 컬러 자료 | `kodachrome AND korea` | 9건 |
```

조회 시점도 함께 적는다. 재공개 상태는 변한다.
