# 논문 활용

판독 결과를 학술 산출물로 옮기는 방법.

## 무엇이 논거가 되는가

발굴 자체는 논문이 아니다. **발굴에서 얻은 것이 어떤 명제를 뒷받침하는가**를 물어야 한다.

이 파이프라인이 산출하는 논거는 대략 넷이다.

| 논거 유형 | 근거 | 논문에서의 쓰임 |
|---|---|---|
| **계량** | 재공개율·표기별 검색 건수 | 접근 가능성의 정량화 |
| **사례** | 개별 자료의 판독 결과 | 원 기술의 한계 실증 |
| **유형화** | 어긋남의 패턴 분류 | 재기술 방법론의 근거 |
| **대조** | 다른 기술 체계와 비교 | 기술 관행의 상대화 |

**네 번째가 가장 강력하다.** 자기 발굴만으로는 「이 자료가 부실하다」에 그치지만,
다른 기술 체계와 견주면 「기술의 상세도가 이용가능성을 좌우한다」는 일반 명제로 간다.

## 계량 — 재현 가능하게

### 반드시 함께 적을 것

```
· 조회 시점 (재공개 상태는 변한다)
· 정확한 쿼리 (재현 가능해야 한다)
· 계량 범위의 한정 (무엇을 세지 않았는가)
```

### 범위 한정의 예

```markdown
결과는 8건이었다. 재공개율은 32퍼센트다(그림 1).

다만 이 값의 범위를 분명히 해 둘 필요가 있다.
이는 특정 재공개 플랫폼에 올라와 있는 비율이며, 접근 가능성 전반의 값이 아니다.
국내 기관이 별도로 수집한 사본이 있을 수 있고 실제로 존재하며,
그러한 수집분은 본 계량에 포함되지 않았다.
```

**한정 없는 수치는 과장이 된다.** 32%를 「접근 가능성」의 값처럼 쓰면
다른 경로로 수집한 기관의 성과를 없는 것처럼 서술하게 된다.

### 계량 도표

```bash
python scripts/make_figure.py stats <데이터.json> --out fig.png
```

연도 분포·계열 분포·확정 유형·판정 분포를 4분면으로 낸다.

## 사례 — 도판 패널

논문에 싣는 도판은 **논거를 보여야** 한다. 예쁜 사진이 아니라 증거다.

```bash
python scripts/make_figure.py panel <사양.json> --out fig.png
```

### 사양

```json
{
  "items": [
    {"img": "read_12.jpg",  "title": "슬레이트 (0:12)",
     "note": "DATE 4/30/48 · FEC 67 CHEJU"},
    {"img": "read_185.jpg", "title": "한글 벽보 (3:05)",
     "note": "손글씨 다수 — 전문 판독 불가"},
    {"img": "t320.jpg",     "title": "항공 촬영 (5:20)",
     "note": "마을에서 피어오르는 연기"}
  ]
}
```

### 캡션 작성

```
그림 3. 111-ADC-7115 (1948.4.30, 제주) — 표제는 「MAY DAY IN KOREA」이나
슬레이트는 4월 30일, 화면은 무장 초소·한글 벽보·항공 촬영이다.
제주 4·3과의 관련은 영상만으로 판별할 수 없으므로 추정하지 않았다.
주민이 등장하는 화면은 게재하지 않았다.
```

캡션에 담을 것:
1. 식별자와 확정된 날짜·장소
2. 무엇이 보이는가
3. **무엇을 판정하지 않았는가**
4. 게재 제한을 적용했다면 그 사실

## 유형화 — 패턴을 표로

개별 사례를 나열하면 일화에 그친다. **유형으로 묶어야 방법론이 된다.**

```markdown
| 유형 | 사례 | 내용 |
|---|---|---|
| 값의 오류 | ADC-5668 | 날짜 1945.1.19 → 1946.1.16 |
| 연결의 오류 | lc-5357 | 다른 기록의 기술이 부착 |
| 「ETC」 은폐 | lc-31631 · 31541 | 전선 포격 / 대통령 방문 |
| 세미콜론 뒤 | lc-29958 | 병기 정비 |
| 표제 vs 슬레이트 | lc-32935 | WOMEN IN WAR → MEDAL PRESENTATION |
| 표제 vs 화면 | lc-31665 | R&R → 전선 진지 |
```

**유형의 개수 자체가 논거다.**
「여섯 유형이 확인되었다는 사실 자체가, 재기술이 표제 수정에 그칠 수 없음을 보여 준다.」

## 대조 — 다른 기술 체계와 견주기

같은 시기·같은 대상을 다룬 **다른 기술 체계**를 찾아 계량 비교한다.

### 비교 항목

| 항목 | 측정 방법 |
|---|---|
| 분량 | 공백 제외 글자 수 |
| 날짜 | 날짜 표기 개수 |
| 인명 | 실명 언급 개수 |
| 수량 | 수치 표기 개수 |
| 장면 구분 | 항목 구분자 개수 |

### 실측 예

| 항목 | 색인형 기술 | 안내형 기술 |
|---|---|---|
| 평균 분량 | 58자 | 253자 (4.4배) |
| 날짜 | 0개 | 2개 |
| 인명 | 0개 | 4개 |
| 장면 구분 | 0.2개 | 7개 |

### ⚠ 우열로 읽히지 않게 한다

**반드시 이 문단을 붙인다.**

```markdown
다만 이 비교를 기술 관행의 우열로 읽어서는 안 된다. 두 체계는 목적이 다르다.
한쪽의 기술은 자국 부대의 촬영 기록을 관리하기 위한 색인이고,
다른 쪽의 기술은 상영 내용을 알리기 위한 안내다.
전자는 식별을, 후자는 전달을 목적으로 한다.

문제는 우열이 아니라, 식별을 위해 만들어진 기술이
팔십 년 뒤 전달의 기능까지 떠맡게 되었다는 데 있다.
```

## 인용 형식

```bash
python scripts/make_figure.py cite <메타.json>
```

### 영상 자료 인용

```
"[표제]," [연대], [기록군] [식별자], NAID [번호],
National Archives and Records Administration, College Park, MD.
재공개: archive.org/details/[식별자] (조회 [날짜]).
```

### 판독 정보를 인용에 포함할 때

원 기술과 다른 사실을 밝혔다면 각주에 근거를 적는다.

```
각주) 카탈로그는 촬영일을 1945년 1월 19일로 기재하나,
필름 0분 15초 지점의 촬영 슬레이트에 「JAN 16 46」이 판독된다.
1945년 1월은 해방 이전이므로 해당 회담이 성립할 수 없으며,
1946년 1월 16일은 미소공동위원회 예비회담 개막일과 일치한다.
소장 기관에 정정을 신고하였다(2026년 8월).
```

## 논문에 반드시 넣을 절

### 방법 절 — 재현 가능성

```markdown
조회는 [날짜]에 수행하였다.
검색어는 [당대 표기 목록]을 병렬 투입하였으며,
각 항목의 재생 가능 여부를 개별 확인하였다.
```

### 한계 절 — 세 가지를 반드시

```markdown
첫째, 대상이 단일 기록군의 특정 시기에 한정된다.
둘째, 접근 가능성을 단일 플랫폼 기준으로 판정하였으므로
      다른 경로의 사본은 반영되지 않았다.
셋째, 판독에 실패한 자료가 있다. [구체적으로 명시]
```

**한계 절이 부실한 논문은 계량의 신뢰도도 의심받는다.**

### 윤리 절 — 게재 판정을 밝힌다

```markdown
검토한 자료는 대부분 퍼블릭 도메인이다.
그럼에도 [N]건은 도판에 싣지 않았다. 기준은 권리가 아니라 피촬영자의 처지다.
[네 단계 기준 표]
```

## 논문과 발굴 문서의 관계

| 문서 | 성격 | 수치 |
|---|---|---|
| 발굴 일지 | 시점별 기록 | 그 시점의 값 — 갱신하지 않음 |
| 재기술 문서 | 자료별 상세 | 확정치 |
| **논문** | **논증** | **조회 시점 명기한 확정치** |

**발굴 일지의 과거 수치를 논문으로 옮기지 않는다.**
논문을 쓸 때 다시 조회해 시점과 함께 적는다.

정합 검사(`check_consistency.py`)로 문서 간 수치 어긋남을 잡을 수 있다.
