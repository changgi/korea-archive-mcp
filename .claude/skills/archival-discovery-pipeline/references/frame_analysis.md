# 프레임 분석과 개체 판독

영상에서 정보를 뽑아내는 방법. **이 파이프라인의 핵심이다.**

## 작업 순서

```
① 개관    전 구간을 한 장으로 훑는다        analyze_video.py survey
② 탐지    문자가 있을 만한 지점을 찾는다     analyze_video.py textscan
③ 판독    그 지점만 고배율로 다시 뽑는다     analyze_video.py zoom
④ 전환    한 릴에 여러 주제가 있는지 본다    analyze_video.py scenes
⑤ 기록    판독 결과를 구조화한다
```

**순서가 중요하다.** 처음부터 확대 프레임을 뽑으면 어디를 확대할지 알 수 없다.

---

## ② 문자 후보 탐지의 원리

슬레이트·표지판은 화면에서 **고대비 + 규칙적 엣지**로 나타난다.
스크립트는 이를 점수화한다.

```
점수 = 국소대비 × (0.5 + 명암분리도) × 밝기페널티
```

| 점수대 | 해석 |
|---|---|
| 18 이상 | 슬레이트 가능성 — 흰 판에 검은 글씨 |
| 12~18 | 표지판·간판 가능성 |
| 12 미만 | 일반 장면 |

**점수가 낮아도 문자가 있을 수 있다.** 자동 탐지는 후보를 좁히는 도구이지 판정이 아니다.
그리드를 눈으로 훑는 과정을 대체하지 않는다.

---

## ③ 판독이 안 될 때

같은 지점을 여러 파라미터로 뽑아 최선을 고르는 것이 기본이다.
그래도 안 되면 순서대로 시도한다.

| 시도 | 방법 |
|---|---|
| 1 | `--crop` 으로 영역을 좁힌다 — 화면의 1/4만 뽑으면 실질 해상도가 4배 |
| 2 | `--scale` 을 높인다 (기본 1050 → 1600) |
| 3 | 앞뒤 프레임을 훑는다 — 흔들림이 덜한 프레임이 있다 |
| 4 | 밝기 보정 — 어두운 원본은 `eq=brightness` 추가 필요 |

**그래도 안 되면 실패를 기록한다.**

```
· 벽보 전문 판독 실패 — 손글씨 한글, 해상도 한계
· 표지판 하단 부대 번호 판독 실패 — 흐림
```

**고해상도 사본 재판독을 후속 과제로 남긴다.** 판독 실패는 부끄러운 것이 아니다.
추정해서 옮겨 적는 것이 부끄러운 것이다.

## 이미지 분석기 활용

```bash
python scripts/analyze_image.py <이미지> --out <디렉터리>
```

### 무엇을 해 주는가

| 기능 | 실용성 |
|---|---|
| **문자 영역 탐지** | ★★★ — 어디를 볼지 알려 준다 |
| 영역 잘라내기 | ★★★ — 확대된 판독용 조각 |
| OCR 전수 시도 | ★ — 대부분 실패, 참고만 |
| **텍스트 식별** | ★★★ — 판독한 문자열의 구조화 |

### 텍스트 식별이 가장 유용하다

판독은 사람이 하고, 그 결과를 넣으면 구조를 뽑아 준다.

```bash
python scripts/analyze_image.py --identify "DATE 4/30/48 UNIT FE SIGNAL C CORPS SCENE FEC 67 CHEJU ROLL 3"
```

```
■ 슬레이트 필드
  date        4/30/48
  unit        FE SIGNAL C CORPS
  scene       FEC 67 CHEJU
  roll        3

■ 날짜 후보
  4/30/48  →  1948년 4월 30일   (미군 자료는 월/일/년 순)

■ 지명
  CHEJU  →  제주

■ 부대 추정
  통신대 (Signal Corps) · 극동 통신대 (Far East)
```

**날짜 표기 오독을 막는 것이 핵심이다.**
`4/30/48`을 30일 4월로 읽으면 안 되고, `JAN 16 46`은 1946년이다.

### ⚠ OCR의 한계

| 대상 | 결과 |
|---|---|
| 인쇄체 영문 대문자 | 부분 성공 — 「WE DENOUNCE」 정도는 잡힌다 |
| **손글씨** | **사실상 실패** — 슬레이트 기입 내용 대부분 |
| **한자·세로쓰기** | **사실상 실패** |

실제 시험에서 「泰東樓 中華料理」 간판은 OCR이 전혀 읽지 못했으나,
잘라낸 조각을 육안으로 보니 완전히 판독됐다.

**OCR 결과를 그대로 재기술에 옮기지 않는다.**
스크립트는 어디를 볼지 알려 주는 도구이지, 읽어 주는 도구가 아니다.

## 슬레이트 판독

가장 확실한 정보원. 필드가 정형화되어 있어 무엇을 찾을지 알 수 있다.

### 표준 필드

```
DATE        촬영일 — 가장 중요
UNIT        촬영 부대
SCENE       과제명·과제번호
ROLL        릴 번호 — 자매편 판별의 열쇠
CAMERAMAN   촬영자
OFFICER     담당관
CAMERA      기종 (Eymo 등)
EFFECT      Day/Night
```

### 판독 예시

```
DATE:  4/30/48        UNIT:  FE SIGNAL C CORPS
SCENE: FEC 67 CHEJU   ROLL:  3
CAMERAMAN: SHAYDAK
```

여기서 얻는 것:
- 촬영일 **1948년 4월 30일** 확정
- 촬영 단위 **극동 통신대**
- 과제 **FEC 67**, 지역 **CHEJU** — 같은 과제의 다른 릴이 있을 수 있다
- **ROLL 3** — 1·2번 릴을 찾아야 한다

### 날짜 표기 주의

미군 자료는 `M/D/Y` 순이다. `4/30/48`은 4월 30일이지 30일 4월이 아니다.
`JAN 16 46` 같은 문자 표기가 섞이기도 한다.

**카탈로그 날짜와 다르면 그 차이를 기록한다.**
어느 쪽이 맞는지 단정하지 말고, 근거를 함께 적는다.

## 슬레이트가 없을 때

포기하지 않는다. **다른 문자가 슬레이트를 대신한다.**

| 대상 | 얻을 수 있는 것 | 실제 사례 |
|---|---|---|
| 다리·시설 표지판 | 장소명 | `FREEDOM GATE BRIDGE` |
| 수용동 번호 | 시설 구조 | `ENCLOSURE 10` |
| 부대 표지 | 소속 부대 | `2nd ROCKET F.A. BTRY` |
| 상점 간판 | 지역·업종 | `泰東樓 中華料理` · `世信商會` |
| 현수막 | 사건의 성격 | `信託統治決死反對` · `祝 政府樹立` |
| 건물 표기 | 시설 종류 | `MESS HALL` · `ATHLETICS AND RECREATION` |
| 차량 번호 | 부대·시기 | 후드 번호 |
| 필름 리더 | 사본 세대 | `Source: U-matic (R copy)` |

**한 건에서 열 가지 이상의 문자가 나오는 경우도 있다.** 전부 기록한다.

## 개체 분석

문자 외에 화면에서 읽을 수 있는 것들. **단정하지 않는 것이 원칙이다.**

### 판독 가능한 것

| 개체 | 얻을 수 있는 것 | 주의 |
|---|---|---|
| 부대 마크 | 사단·연대 식별 | 흐리면 추정하지 않는다 |
| 복장 | 계절·병과·소속 구분 | 포로와 경비의 구분은 복장만으로 단정 못 함 |
| 차량·항공기 | 기종·시기 | **기종 특정은 전문 지식 영역** — 하지 않는 편이 낫다 |
| 건축 양식 | 시설 종류·지역 | 동시기 사진과 대조해야 비정 가능 |
| 지형 | 촬영 지점 추정 | 능선·해안선은 강력한 단서이나 확정은 어렵다 |
| 인원 규모 | 행사 규모 | 「다수」로 적고 숫자는 세지 않는다 |

### 하지 않는 것

- **인물 비정** — 슬레이트에 이름이 있어도 그 사람이 누구인지는 별개
- **기종 특정** — 「T-6으로 보이나 특정하지 않음」이 정직하다
- **부대 추정** — 마크가 흐리면 「미확인」
- **날짜 역산** — 그림자 각도나 초목으로 계절을 추정하지 않는다

> 개체 분석은 **판독**이지 **감정**이 아니다.
> 화면에 찍힌 것을 읽는 데 그치고, 전문 감정이 필요한 판정은 넘긴다.

## ④ 장면 전환 — 표제가 숨긴 것을 찾는다

한 릴에 여러 주제가 편집된 경우가 많다.

**표제에 다음이 있으면 전환 탐지가 필수다:**

| 신호 | 의미 |
|---|---|
| `; ETC` | 뒤에 무엇이 있는지 알 수 없다 |
| 세미콜론 | 두 번째 주제가 있다 |
| 쉼표 뒤 다른 지명 | 촬영지가 여럿이다 |

### 실제로 나온 것들

| 표제 | 「ETC」·세미콜론 뒤 |
|---|---|
| `EISENHOWER VISITS KOREA; ETC` | **대한민국 대통령의 극동사령부 방문** |
| `FREEDOM MEDAL PRESENTATION; ETC` | 전선 포격·부교 도하 |
| `POLITICAL RALLY, SEOUL; 2ND ORDNANCE` | 병기 정비 |
| `INDEPENDENCE CELEBRATION; FIRE FIGHTING` | 화재 진압 |

**뒷부분이 앞부분보다 사료 가치가 높은 경우도 있다.**

## ⑤ 판독 결과 기록법

구조화해 적는다. 나중에 논문·보고서로 옮길 수 있는 형태로.

```markdown
### 화면 속 문자

| 시각 | 대상 | 판독 내용 | 신뢰도 |
|---|---|---|---|
| 0:12 | 슬레이트 | DATE 4/30/48 · FEC 67 CHEJU · SHAYDAK | 완전 |
| 3:05 | 벽보 | (손글씨 한글 5장 이상) | **판독 실패** |
| 5:20 | — | 항공 촬영 — 문자 없음 | — |

### 개체

| 시각 | 개체 | 판독 | 미판정 |
|---|---|---|---|
| 1:35 | 방벽·무장 인원 | 모래주머니 초소 형태 | 소속 부대 미확인 |
| 6:05 | 기관총 | 거치 상태·사격 자세 | **기종 특정 안 함** |
```

**신뢰도 표기를 반드시 붙인다** — 완전 / 부분 / 실패.
