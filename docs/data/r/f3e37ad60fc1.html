요약1955년 9월 3일 삼일정신선양회 경상북도본부에서 발행한 '삼일운동사'. 총70쪽. 스테이플러 심으로 편철된 형태임. 내용은 '선언문, 서설, 국제연맹의 성립과 3·1 운동의 동기, 싹트는 민족자결주의와 약소민족의 기운, 영도자 손병희선생, 운동의 원칙과 진행, 교단의 단결과 함태영씨의 노력, 독립선언문의 작성, 3월 1일의 의의와 운동의 방식, 33인의 서명과 선언서 인쇄와 운반, 준비완료와 33인의 사전회의, 3·1운동의 전개, 학생단의 시가행진, 민족대표의 피검투옥과 운동의 결과와 개황, 운동의 강령과 우리 민족정신, 공판기발췌(최, 이, 함 3씨), 재판의 경로, 경성지방법원 예심종결 결정서(원문역), 경성고등법원 특별재판부 결정서(원문역), 경성복심법원 결정서(원문역), 3·1정신선양회 취지서,
권리권리(원문): 공공누리 제4유형 — 출처 표시 + 상업적 이용금지 + 변경금지 (원형 그대로만 — 자르기·글씨·필터 금지) (기록 메타(원 기관 판독))
