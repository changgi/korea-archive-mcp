연대광복 이후(1945~)
요약1959년 개봉한 윤봉춘(尹逢春) 감독의 영화 '유관순(柳寬順)'을 홍보하기 위해 발행한 인쇄물. 도금봉(都琴峰), 고설봉(高雪峰), 한은정(韩恩贞) 등 출연. 동보영화사(東寶映畵社) 제작. 앞면에 '주연 都琴峰 柳寬順', '初日부터 連日 満員謝禮', '斷然! 運營方針을 革新! 永登浦地區封切舘으로 新彂足!!' 등의 문구가 인쇄되어 있음. 뒷면에 지방주재 사원을 모집하는 글이 수기됨.
권리권리(원문): 공공누리 제4유형 — 출처 표시 + 상업적 이용금지 + 변경금지 (원형 그대로만 — 자르기·글씨·필터 금지) (기록 메타(원 기관 판독))
