요약판우회(板友會)에서 발행한 계간(季刊) 종합 잡지 판문점(板門店) 1969년 7월 15일호(창간호). 제1권 제1호. 표지 2장, 본문 180쪽. 앞면 우측 가장자리가 스테이플러 심으로 고정된 형태. 본문은 판문점 변천에 관한 화보와 창간사를 시작으로 이동준(李東濬)의 '北傀權力構造의 어제와 오늘', 윤종현(尹宗鉉)의 '北傀軍事力의 增强과 속셈', 신상초(申相楚)의 '白頭山紛爭', 김용수(金龍洙)와 이동준 등 8명이 참여한 좌담회 '板門店十六年', 최덕신(崔德新)의 '停戰協定調印前後', 김점균(金点坤)과 이도연(李度珩)이 참여한 대담 '主人잃은 板門店', 이호철의 소설 '첫 戰鬪' 등이 게재됨. 판우회(板友會)는 판문점(板門店)을 출입하는 기자들의 모임임.
권리권리(원문): 공공누리 제4유형 — 출처 표시 + 상업적 이용금지 + 변경금지 (원형 그대로만 — 자르기·글씨·필터 금지) (기록 메타(원 기관 판독))
