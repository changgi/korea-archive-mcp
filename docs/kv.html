KV (Korea Archive Viewer) 사용법
· 컬렉션을 열면 모든 기록의 모든 이미지가 한 줄로 이어집니다 — ‹ › · ← → · 썸네일 띠 · 자동 넘김이 기록 경계를 넘어 계속 넘어갑니다(아래 띠 = 전체, 노란 번호 = 기록 경계).
· 주소창에 IIIF 매니페스트·컬렉션 URL을 넣고 열기 — 우리 갤러리·Internet Archive·Europeana·Gallica·NDL 등 어디 것이든(v2·v3). 컬렉션은 왼쪽 목록에서 고릅니다.
· 주소로 바로 열기: kv.html?manifest=<URL> (또는 ?iiif-content=) · 특정 장: &canvas=3 · 비교: &compare=<URL2>
· ←→ 넘김 · Space 자동 넘김 · R 회전 · F 전체 화면 · C 비교 · 마우스 휠·두 손가락으로 확대
· ⧉ 비교: 화면을 둘로 나눠 서로 다른 기록을 나란히 — 누른 창(노란 테두리)이 목록·넘김의 대상이 됩니다.
· 권리: 이미지마다 오른쪽 정보 패널의 권리·출처를 확인하세요. 기관 IIIF는 원 기관이 제공하는 원본입니다.
