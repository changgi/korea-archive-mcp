02연합 검색망

한국어 질의는 각 문서고의 색인 언어로 자동 변환됩니다(장진호→Chosin Reservoir·長津湖, 병인양요→expédition de Corée). 복수 문서고가 같은 기록을 내면 교차확인으로 표시합니다.

발굴 우선 원칙 — 권리·접근 제약은 발굴을 막는 사유가 아니라 표시 대상입니다. 결과마다 권리 상태를 표시하고(KOGL 1~4유형 · NARA Use Restriction 실조회), 게재 단계에서 사람이 최종 확정합니다.

03발굴이 기록이 됩니다 — 현용기록물화 사슬

검색 결과를 흘려보내지 않습니다. 발굴 행위 자체가 표준 지향 기록이 되어 변환·전파·검증됩니다.

생산
JSON-LD 수집기록 매니페스트(ISAD(G)·RiC 지향) — 재현 호출문·채널 통계가 증거성, 기관 정식명·영속 식별자·상위 계층(partOf 28채널)이 맥락
데이터화
CSV(partOf·media 열)·지식그래프(series 노드·PART_OF 엣지)·매니페스트가 같은 node 키를 공유 — 스프레드시트·Gephi·Neo4j·KARDA 직투입
전파
보고서·카드뉴스·포스터가 매니페스트를 부록으로 상속하고, 이미지도 media 직링크(NARA·Commons 실조회 원본)에서 소싱 — 데이터와 지면의 계보 일치
지속
sha256 fixity + 본문 지문 10채널 + 공개 지문 원장(골든 8종 주간 재계산·개정 이력) — 재판독 지문 불일치는 원문 개정 발생의 신호

04발굴을 깊게 만드는 장치

심층 판독 14채널

발굴한 번호·URL을 재투입하면 본문이 나옵니다 — 공훈록 전문, 판결문 사건개요·주문, 장서각 해제, 국가유산 해설, 신문 OCR 원문, UN 요약+6개 언어 PDF, NARA 계보·소장단위·디지털 객체.

인접 채굴

하나 찾으면 양옆을 훑습니다. NARA NAID ±N(계보로 시리즈 경계 탐지)·TNA·IA 일련번호·6·25아카이브 archRfcd — 같은 컬렉션의 절반이 다른 표기로 숨어 있는 사례를 복구합니다.

당대 표기 팬아웃

variants=true — Corea·Chosen·Keijo·Fusan 등 당대 표기를 해외 채널에 자동 병렬 투입. 현대어 검색이 놓치는 19세기~일제기 기록을 건집니다.
