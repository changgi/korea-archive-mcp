## 시연 질의 10선 (실측 완료)
1. **다국어 변환**: `tna_search("임진강", year_from=1950, year_to=1953)` — 영문 자동 변환 + 연대 필터(Korea 13,533→2,553건 축소 실측).
2. **협약기관**: `koreanwar_search("인천상륙")` — 55,000+ 소장, NARA RG 역추적 링크. `scope="battle"`로 전투정보(기관 69건+서버 앵커 16건 — "백마고지"로 앵커 시연).
3. **인접 채굴 4기관**: `nara_search(naid=22015, radius=2)` — 인천상륙 D-DAY 연속 필름(111-ADC-8247~8251) 일괄 발굴 실측. `ia_search(identifier="111-adc-10076", radius=2)` — 4건 실존.
4. **교차검색 13소스**: `cross_search("장진호")` — 채널별 건수 태그, 복수출처=교차확인.
5. **당대 표기 팬아웃**: `cross_search("한국전쟁", variants=true)` — `ia·Corean` 변형만으로 추가 4건 실측.
6. **분석 투입**: `cross_search("장진호", format="csv")` — CSV 직출력.
7. **고문서**: `nedb_search("송준길", mode="aks")` — 소장처 172곳→분류→문서 266건→건별 27면 썸네일 실측.
8. **권리 표시**: `judge_rights("KOGL 1")` → Class A 자동 판정. `nara_search(..., record_group=111)` → 권리 초판정 라인 자동 부착.
9. **자가 점검**: `source_profile("health")` — 13채널 골든 질의 실측(주간 CI 자동 실행).
10. **매직 키워드**: "장진호 풀패키지로 만들어줘" → full_package 오케스트레이션 / "창기창기 도와줘" → help.
